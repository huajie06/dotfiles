# Ghostty Cheatsheet — Tab & Pane Manipulation

## Setup

```bash
ln -sf "$PWD/ghostty/config" ~/.config/ghostty/config
```

## Tabs

| Action              | Key              |
|---------------------|------------------|
| New tab             | `Super+T`        |
| Close tab           | `Super+W`        |
| Next tab            | `Super+Tab`      |
| Previous tab        | `Super+Shift+Tab`|
| Go to tab 1–9       | `Super+1` … `9`  |
| Reorder tab left    | `Super+Shift+Left`|
| Reorder tab right   | `Super+Shift+Right`|

## Panes (splits)

| Action              | Key              |
|---------------------|------------------|
| Split right         | `Super+D`        |
| Split down          | `Super+Shift+D`  |
| Close pane          | `Super+W`        |
| Next pane           | `Super+Alt+Right`|
| Previous pane       | `Super+Alt+Left` |
| Resize pane left    | `Super+Ctrl+Left`|
| Resize pane right   | `Super+Ctrl+Right`|
| Resize pane up      | `Super+Ctrl+Up`  |
| Resize pane down    | `Super+Ctrl+Down`|
| Toggle pane zoom    | `Super+Shift+Enter`|
| Toggle pane fullscreen | `Super+Enter` |

## Misc

| Action              | Key              |
|---------------------|------------------|
| Copy selection      | `Super+C`        |
| Paste               | `Super+V`        |
| Search              | `Super+F`        |
| Quick config edit   | `Super+,`        |
| Reload config       | `Super+Shift+,`  |
