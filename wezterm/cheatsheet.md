# WezTerm Cheatsheet — Tab Manipulation

## Default keybindings

| Action                          | Key                      |
|---------------------------------|--------------------------|
| New tab                         | `Ctrl+Shift+T`           |
| Close current tab               | `Ctrl+Shift+Q`           |
| Next tab                        | `Ctrl+Tab`               |
| Previous tab                    | `Ctrl+Shift+Tab`         |
| Go to tab 1–9                   | `Alt+1` … `Alt+9`        |
| Search / activate tab by name   | `Ctrl+Shift+X` (Activation Picker) |
| Move tab (reorder)              | `Ctrl+Shift+Left/Right`  |
| Show tab bar toggle             | `Ctrl+Shift+Alt+T`       |
