# dotfiles

Personal dotfiles — Emacs 30.2 config, VSCode settings, and shell scripts.

## Emacs

Modular Evil-based config for Python data science and Org mode. See [emacs/README.md](emacs/README.md) for the full architecture.

**Quick start** — add this to `~/.emacs.d/init.el`:

```elisp
(load "~/repos/dotfiles/emacs/init.el")
```

Everything else is resolved from the repo path automatically. No copying needed.

## VSCode

Backed-up `settings.json` with Vim bindings, Ruff formatting, and misc preferences. Not auto-deployed.
